AI/ML Course Curriculum

This course is designed to take students from foundational programming skills to building AI models independently. Each module includes a mini-project, and at the end of the course, students will complete a major AI/ML project.

Modules

Module 1: Python for AI Development

  • Python Basics: Variables, Data Types, Conditional Statements, Loops
  • Functions & Lambda Expressions
  • Object-Oriented Programming (OOP) – Classes & Objects
  • File Handling (Reading/Writing CSV, JSON, and Text files)
  • Exception Handling
  • Python Modules & Package Management (pip, virtual environments)
  • Mini-Project: Automating a task using Python (e.g., Web Scraper, File Organizer)

Module 2: Data Structures & Algorithms (DSA)

  • Time & Space Complexity Analysis (Big O Notation)
  • Arrays & Linked Lists
  • Stacks & Queues
  • Hashmaps & Hashsets
  • Searching Algorithms (Binary Search, Linear Search)
  • Sorting Algorithms (Merge Sort, Quick Sort, Heap Sort)
  • Recursion & Dynamic Programming
  • Graph Algorithms (BFS, DFS, Dijkstra’s Algorithm)
  • Mini-Project: Implementing a real-world problem using DSA (e.g., Pathfinding Algorithm, Scheduling System)

Module 3: Python Libraries for Data Science

  • NumPy: Arrays, Broadcasting, Linear Algebra Operations
  • Pandas: DataFrames, Data Manipulation, GroupBy, Pivot Tables
  • Seaborn & Matplotlib: Data Visualization (Bar Charts, Heatmaps, Histograms, Boxplots)
  • Regular Expressions (Regex): Pattern Matching, Data Cleaning
  • Mini-Project: Data Analysis & Visualization (e.g., COVID-19 Data Analysis, Stock Market Trends)

Module 4: Mathematics for ML & SQL

  • Probability & Statistics: Mean, Median, Mode, Probability Distributions, Hypothesis Testing
  • Linear Algebra: Vectors, Matrices, Dot Product, Eigenvalues
  • SQL for Data Science: Basic Queries, Joins, Indexing, Performance Optimization
  • Mini-Project: SQL-based Data Analysis (e.g., Sales Data Analysis, Customer Segmentation)

Module 5: Machine Learning (Supervised & Unsupervised)

  • Supervised Learning: Regression, Decision Trees, SVM, XGBoost
  • Unsupervised Learning: K-Means Clustering, PCA, Anomaly Detection
  • Feature Engineering & Model Tuning
  • Mini-Project: Predictive Analytics Model (e.g., House Price Prediction, Fraud Detection)

Module 6: Deep Learning & NLP

  • Deep Learning Fundamentals: Neural Networks, CNNs, Transfer Learning
  • NLP: Tokenization, Word Embeddings, Named Entity Recognition, Transformers
  • Mini-Project: Image Classification or NLP-based Model (e.g., Fake News Detection, Handwritten Digit Recognition)

Final Major Project

Students will work on an end-to-end AI/ML project that integrates everything learned in the course.

Project Components:

  • Data Collection & Preprocessing
  • Model Building & Optimization
  • Deployment using Flask/FastAPI/Streamlit
  • Presentation & Resume Guidance

Example Projects:

  • AI-powered Resume Screening System
  • Autonomous Vehicle Object Detection
  • AI-based Personal Finance Assistant
  • AI-driven Chatbot for Customer Support
